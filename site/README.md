# Сайт JARVIS

Обычный статический сайт: HTML, CSS и JavaScript, сборка не нужна.

- Настройки и источник установщика: `config.js`
- Просмотр у себя на компьютере: `cd site && python3 -m http.server 8000`, затем открой http://127.0.0.1:8000
- Публикация на GitHub Pages и раздача установщика через Releases: см. `ИНСТРУКЦИЯ_GITHUB.md` рядом с папкой `site`.
